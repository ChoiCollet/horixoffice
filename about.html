사이트 소개

HorixOffice를 만든 이유와, 할 수 있는 것·할 수 없는 것

왜 만들었나요

한컴오피스의 '한컴PDF'를 쓰면서, 프로그램을 설치하지 않고도 브라우저 안에서 PDF를 보고, 원하는 쪽만 골라 인쇄용으로 만들고, 주석을 남기고, 여러 파일을 하나로 합칠 수 있으면 좋겠다는 생각에서 시작했습니다. 한PDF처럼 익숙한 배치(파일·홈·보기·주석·프레젠테이션·도구)를 그대로 따라서, 처음 써도 어디에 무엇이 있는지 바로 찾을 수 있게 만들었어요. 컴퓨터와 휴대폰 모두에서 쓸 수 있어요.

이름의 유래

HorixOffice는 지평선을 뜻하는 Horizon에서 따왔어요. PC 화면 안에 갇혀 있던 문서를 웹 브라우저라는 넓은 지평선 위로 풀어놓겠다는 뜻이에요. 'Horizon'의 끝을 살짝 비틀어 Horix로 줄이고, 문서를 다루는 도구라는 의미로 Office를 붙였어요.

다만 'Office'라는 이름은 워드·엑셀까지 되는 종합 오피스를 떠올리게 할 수 있어요. HorixOffice는 PDF 전용 도구예요. 다른 형식의 문서를 직접 편집하지는 않고, PDF를 보고·꾸미고·나누고·합치고·다른 형식으로 내보내는 일을 도와줘요.

무엇을 할 수 있나요

탭기능
파일불러오기, 저장하기(주석 포함), 다른 이름으로 저장, 빈 문서·서식 문서(줄 노트·모눈종이·점 모눈·코넬 노트·5선 악보) 만들기, 문서 정보, 인쇄, 사용자·스킨 설정, 최근 파일 다시 열기, 암호가 걸린 PDF 열기
홈글자 선택·복사, 찾기, 손도구, 화면 캡처, 확대/축소·쪽 맞춤, 쪽마다 따로 회전, 작업창(개요·첨부 파일·주석 속성), PDF 병합(파일마다 원하는 쪽만 골라 합치기)
보기한 쪽씩 보기 / 연속 보기, 페이지 패널, 주석 표시, 도구 상자 보이기·숨기기
주석선·화살표·도형·자유형, 글자에 딱 맞는 형광펜·밑줄·취소선, 스티커노트, 선택·이동·크기 조절, 실행 취소/다시 실행. 저장한 파일을 다시 열어도 주석을 고칠 수 있어요
프레젠테이션전체 화면 슬라이드쇼와 화면 전환 효과 9가지(닦아내기·밀어내기·계단 모양·모자이크·빗질하기·실선 무늬·자르기·밝기 변화), 방향·시간·모니터 설정
도구쪽 추출하기, 선택 영역 내보내기(이미지·잘라낸 PDF·글자), 한컴 사전·번역·실시간 검색, 그림(PNG)·DOCX·PPTX·XLSX로 변환

할 수 없는 것

  • HWP로 변환 — 한글과컴퓨터의 비공개 형식이라 브라우저에서 만들 수 없어요.
  • DOCX·XLSX 변환의 정확한 재현 — 글자를 읽어서 문단·칸으로 만들기 때문에 표 모양·서식·그림 위치까지 똑같이 옮기진 못해요. PPTX는 쪽마다 그림 한 장이에요.
  • 로그인·클라우드 저장 — 서버가 없는 사이트라서 계정이나 클라우드 동기화는 없어요.
  • 암호·권한 제한이 걸린 PDF — 볼 수는 있지만, 합치기·쪽 추출·PDF 잘라내기는 제한돼요. 저장할 때는 쪽을 이미지로 바꿔서 저장해요.

어떻게 동작하나요

이 사이트는 별도의 서버 없이 정적으로 동작해요. 불러온 PDF는 어디로도 전송되지 않고, 지금 보고 있는 브라우저 안에서만 열리고 편집되고 저장돼요. 페이지를 그리는 데에는 pdf.js를, 새 PDF를 만드는 데에는 pdf-lib를 사용합니다.
